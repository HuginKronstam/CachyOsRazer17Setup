# Downloaded icon themes

Not backed up as files (can be hundreds of MB, trivially reinstallable).
Reinstall via System Settings > Appearance > Icons > Get New Icons,
search for the name below, or open the homepage link directly. Then
set the active one the same way (or in System Settings > Icons).

- **Colorful-Dark-Icons**: https://store.kde.org/p/2091068
- **Infinity-Dark-Icons** (active): https://store.kde.org/p/1436570
- **Slot Dark Icons**: https://store.kde.org/p/2234790
- **Vivid-Dark-Icons**: https://store.kde.org/p/2110189
